# 検証チェックリスト

## Phase 9A（必須）
- [ ] 開発サーバーが起動する
- [ ] ランタイムエラーがない
- [ ] すべてのルートが認識されている
- [ ] 主要ページが200 OKを返す

## Phase 9B（複雑なUIの場合）
- [ ] ユーザーフローが正常に動作
- [ ] Core Web Vitalsが基準内
  - LCP: 2.5秒以内
  - FID: 100ms以内
  - CLS: 0.1以内
- [ ] アクセシビリティツリーが適切
- [ ] レスポンシブデザインが正しく動作
  - Mobile: 375px
  - Tablet: 768px
  - Desktop: 1024px
  - Wide: 1920px
- [ ] ブラウザコンソールにエラーなし

## トラブルシューティング

### ランタイムエラーが出る場合
1. エラーメッセージを確認
2. スタックトレースで原因ファイルを特定
3. Phase 5（実装）に戻って修正

### パフォーマンスが悪い場合
1. Chrome DevToolsでプロファイリング
2. 重い処理を特定
3. Phase 7（コードレビュー）で最適化
