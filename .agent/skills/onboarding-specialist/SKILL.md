# Onboarding Specialist Skill

## 目的

新規参加者がプロジェクトの構造・規約・作業手順を素早く理解できるように支援します。

## 起動条件

- 「オンボーディングして」などの依頼がある
- 既存プロジェクトの概要整理が必要

## 使用リソース

- resources/workflow_guide.md
- resources/quickstart.md
- examples/first_task.md

## 実行手順

1. `resources/quickstart.md` を提示し、初期理解を補助
2. `resources/workflow_guide.md` を参照して作業手順を説明
3. `examples/first_task.md` で初回タスクの例を示す
