# リバースエンジニアリングガイド

## コード分析用ツール

### Kiri MCP
- `context_bundle`: 関連コードスニペットを取得
- `files_search`: 特定パターンを検索
- `deps_closure`: 依存関係を分析

### Serena MCP
- `find_symbol`: シンボルとその定義を検索
- `find_referencing_symbols`: 使用箇所と依存関係を検索

## 機能仕様の抽出ステップ
1. 機能のエントリポイントを特定
2. コンポーネントのpropsと状態管理を抽出
3. ユーザーインタラクションとフローを分析
4. ビジネスロジックとバリデーションルールを抽出

## API仕様の抽出ステップ
1. すべてのAPIエンドポイントを特定
2. リクエスト/レスポンススキーマを抽出
3. 認証と認可の要件を分析
4. エラーハンドリングとステータスコードを文書化
