# Phase Planning Skill

## 目的

作業を具体的なタスクに分解し、実装順序を定義します。

## 起動条件

- 実装前のタスク分解が必要
- 複数ステップの作業を計画する

## 使用リソース

- resources/planning_template.md

## 実行手順

1. **タスク分解**
   - 大きな作業を小さなステップに分割
   - 各タスクは独立して完了可能に
   - 1タスクあたり5-15分程度を目安に

2. **実装順序の定義**
   - 依存関係を考慮した順序付け
   - ボトムアップまたはトップダウン
   - テスト可能な単位で区切る

3. **依存関係の特定**
   - 他のコンポーネント/モジュールへの依存
   - 外部ライブラリの追加が必要か
   - APIやデータソースの準備状況

4. **要件の明確化**
   - 不明点や曖昧な点をリストアップ
   - 必要に応じてユーザーに質問
