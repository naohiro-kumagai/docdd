# Storybookストーリー作成ルール

## 基本ルール

1. **条件分岐レンダリングにストーリーを作成**
   - `&&`や`?`で要素を表示/非表示する場合
   - 例: エラー状態、ローディング、空状態

2. **単純なprops値の違いにはストーリーを作成しない**
   - variant、size、colorなどの違いはデフォルトストーリーで十分

3. **非表示状態のストーリーは不要**
   - `isVisible: false`のような状態は作成しない

4. **Meta設定を最小限に**
   - `component`のみを指定

5. **イベントハンドラーには`fn()`を使用**
   - 各ストーリーの`args`で定義

6. **バレルインポート禁止**
   - `@/`エイリアスを使用した個別インポート

7. **ストーリー名は日本語**
   - 視覚的な違いがすぐにわかるように

## チェックリスト
- [ ] propsが表示に与える影響を包括的にカバー
- [ ] 冗長または重複したストーリーはない
- [ ] TypeScript型と命名規則に従っている
- [ ] 視覚的に同一のストーリーはない
