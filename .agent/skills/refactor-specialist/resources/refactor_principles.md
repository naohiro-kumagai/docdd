# リファクタリング原則

## 1. ロジック抽出
- UI以外のロジックを同ディレクトリ内のユーティリティファイルに分離
- `userValidation.ts`のように責務が伝わるファイル名をつける

## 2. Presenterパターン
- 条件分岐するテキストや表示文字列を`presenter.ts`に集約
- 必要なデータを受け取って文字列を返す純粋関数として定義

## 3. 条件分岐UI抽出
- 内部状態で制御される条件分岐を、propsで受け取る新コンポーネントに抽出
- 親コンポーネントが表示バリエーションを制御できるようにする

## 4. Props制御を最優先
- すべての条件レンダリング（loading, error, null check等）は外部からprops制御可能に
- 表示を担当するコンポーネントの内部に状態管理を閉じ込めない

## 5. データ取得にuseEffectを使わない
- Server ComponentsとSuspenseを使用

## 6. Promiseには`.then().catch()`を優先
- try-catchではなく明示的なエラーハンドリング
