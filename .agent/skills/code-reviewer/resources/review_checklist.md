# コードレビュー観点チェックリスト

## 品質
- [ ] 単一責任の原則を守っているか
- [ ] 既存の設計パターンに沿っているか
- [ ] 既存コードとの整合性があるか
- [ ] マジックナンバーの使用を避けているか

## 保守性
- [ ] 命名が明確で読みやすいか
- [ ] コメントが意図の説明になっているか
- [ ] 重複コードがないか

## パフォーマンス
- [ ] 不要な再計算や再レンダリングがないか
- [ ] 大きな処理は分割またはメモ化されているか

## セキュリティ
- [ ] XSSやインジェクションの危険がないか
- [ ] 入力値のバリデーションがあるか

## テスト
- [ ] 重要な分岐にテストがあるか
- [ ] 例外パスがカバーされているか
