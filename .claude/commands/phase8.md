# Phase 8: Quality Checks（品質チェックフェーズ）

このフェーズでは、**静的解析とテストの実行**を行います。

## 実行コマンド

すべてのチェックを順番に実行します：

```bash
# 1. 型チェック
bun run type-check

# 2. Lint
bun run lint

# 3. テスト実行
bun run test

# 4. ビルド確認
bun run build
```

## エラー発生時の対応

### 型エラーの場合

1. `mcp__ide__getDiagnostics`で詳細を確認
2. 型定義を修正
3. 再度`bun run type-check`を実行

### Lintエラーの場合

1. エラーメッセージを確認
2. コードスタイルを修正
3. 再度`bun run lint`を実行

### テスト失敗の場合

1. 失敗したテストのエラーメッセージを確認
2. 期待値と実際の値を比較
3. 実装またはテストを修正
4. 再度`bun run test`を実行

### ビルドエラーの場合

1. エラーメッセージを確認
2. インポートパスやモジュール解決を確認
3. 修正後、再度`bun run build`を実行

## 完了チェックリスト

- [ ] 型チェックが通る
- [ ] Lintエラーがゼロ
- [ ] すべてのテストが通る
- [ ] ビルドが成功
