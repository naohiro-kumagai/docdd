# ワークフロー選択ヘルパー

変更のタイプに応じて最適なワークフローを提案します。

## 変更タイプ別の推奨フロー

| 変更タイプ | 推奨フェーズ | 説明 |
|-----------|-------------|------|
| **新機能追加** | Phase 1-11 全て | 完全なワークフロー |
| **中規模バグ修正** | 1,4,5,6,8,9A,10,11 | 調査→実装→テスト→確認 |
| **UI/デザイン調整** | 1,3,4,5,8,9A,10,11 | UIデザインレビュー含む |
| **小規模リファクタ** | 1,4,5,8,10,11 | 既存パターン踏襲 |
| **タイポ修正** | 5,8,10,11 | 設定ファイルや小さな修正 |
| **ドキュメント更新** | 5,10,11 | ドキュメントのみの変更 |

## 利用可能なフェーズスキル

- `/phase1` - Investigation & Research（調査）
- `/phase4` - Planning（計画立案）
- `/phase5` - Implementation（実装）
- `/phase8` - Quality Checks（品質チェック）
- `/phase9` - Runtime Verification（動作確認）
- `/phase10` - Git Commit（コミット）

## 利用可能なユーティリティスキル

- `/ui-review` - UI/UXデザインレビュー
- `/adr-record` - アーキテクチャ決定記録の作成
- `/test-gen` - テストコード生成
