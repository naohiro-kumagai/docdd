# Phase 4: Planning（計画立案フェーズ）

このフェーズでは、**タスクの細分化と実装順序の決定**を行います。

## 前提確認

- [ ] Phase 1のADR確認が完了していること
- [ ] UI変更がある場合、Phase 3（UI/UXデザイン）が完了していること

## 実行手順

### 1. タスク分解

作業を以下の観点で細分化します：

- **ファイル単位**: どのファイルを作成/変更するか
- **機能単位**: 各機能の実装順序
- **依存関係**: タスク間の依存関係

### 2. TodoWriteでタスク登録

```
TaskCreateツールを使用してタスクを登録:

- subject: タスクのタイトル（命令形）
- description: 詳細な説明
- activeForm: 進行中の表示（現在分詞形）
```

### 3. 実装順序の決定

以下の順序で実装することを推奨：

1. **型定義・インターフェース**: 最初に型を定義
2. **ユーティリティ関数**: 共通ロジック
3. **コンポーネント**: UIコンポーネント
4. **統合**: 各部品の統合
5. **テスト**: テストコード作成

## タスク登録例

```markdown
## 実装タスク

1. [ ] `User`型インターフェースを定義
2. [ ] `validateUser`ユーティリティ関数を実装
3. [ ] `UserCard`コンポーネントを作成
4. [ ] `UserList`ページに統合
5. [ ] テストコードを作成
```

## 完了チェックリスト

- [ ] Phase 1のADR確認が完了している
- [ ] UI変更がある場合、Phase 3が完了し承認を得ている
- [ ] TodoWriteで全タスクを登録
- [ ] タスクの実行順序を決定
- [ ] 依存関係を明確化
- [ ] 不明点をすべて解消

---

**質問**: 実装する機能の概要を教えてください。タスクを細分化して計画を立てます。
